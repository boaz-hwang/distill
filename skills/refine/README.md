# refine

Give an existing skill a clearer, leaner structure.

[한국어](README.ko.md) · [Skill instructions](SKILL.md) · [MIT](LICENSE)

Refine reviews the whole skill and its resources, removes unnecessary guidance, and preserves the requirements its result depends on. Execution records are useful but not required.

## Install

```text
Clone https://github.com/boaz-hwang/skilloom and install skills/refine as refine in your skills directory.
```

## Use

```text
Use refine to restructure <skill-name> around its purpose and essential requirements.
```

## How it works

1. Read the intended result, constraints, and supporting resources.
2. Review deletion first; shorten, revise, or restructure only where useful.
3. Verify according to the impact of the changes and apply supported revisions.

Refine handles one skill. A clearer file is not automatically proof of better execution performance.
