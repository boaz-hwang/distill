# distill

Turn the task you just completed into a skill.

[한국어](README.ko.md) · [Skill instructions](SKILL.md) · [MIT](LICENSE)

You get a skill that performs the task for you when you invoke it. Distill extracts the essentials from the result and feedback in a completed work session.

## Install

```text
Clone https://github.com/boaz-hwang/skilloom and install skills/distill as distill in your skills directory.
```

## Use

```text
Use distill to turn this task into a reusable skill.
```

## How it works

1. Recommend one of three names and confirm a one-line outcome.
2. Propose the shortest sufficient process and confirm any revisions.
3. Create concise guidance with needed resources, code checks, and human review questions.

Invoke it in the session where you completed the task and accepted the result.
