# distill

방금 수행한 업무를 skill 로 남기세요.

[English](README.md) · [스킬 본문](SKILL.md) · [MIT](LICENSE)

호출하면 업무를 대신 수행해줄 skill 을 남깁니다. 완료한 업무의 결과와 피드백에서 재현에 필요한 핵심만 추출합니다.

## 설치

```text
https://github.com/boaz-hwang/skilloom 을 git clone해서 skills/distill를 네 스킬 폴더에 distill로 설치해줘.
```

## 사용

```text
distill로 이 업무를 재사용 가능한 스킬로 만들어줘.
```

## 동작

1. 이름 후보 3개 중 하나를 추천하고 결과물 한 줄 설명을 확인받습니다.
2. 최소한의 핵심 과정을 제안하고, 수정한 과정은 다시 확인받습니다.
3. 간결한 지침과 필요한 자료·검증 코드·사람 평가 질문을 만듭니다.

업무 결과에 만족하면 작업한 세션에서 호출하세요.
