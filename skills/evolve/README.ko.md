# evolve

실제 사용 기록을 바탕으로 스킬을 개선하세요.

[English](README.md) · [스킬 본문](SKILL.md) · [MIT](LICENSE)

스킬 하나의 실행 기록에서 실패와 낭비를 찾아 관련 부분만 최소 수정합니다. 삭제부터 검토하되, 반영 기준은 기존 품질 유지입니다.

## 설치

코딩 에이전트에 아래 한 줄을 붙여넣으세요.

```text
https://github.com/boaz-hwang/skilloom 을 git clone해서 skills/evolve를 네 스킬 폴더에 evolve로 설치해줘.
```

## 사용

대상 스킬을 사용한 세션에서 요청하거나, 관련 기록을 함께 제공하세요.

```text
evolve로 <스킬 이름>의 사용 기록을 검토하고 근거가 있는 부분만 최소한으로 개선해줘.
```

## 동작

1. 실제 사용·결과·피드백에서 개선할 문제를 찾습니다.
2. 삭제부터 검토하고, 축약·수정으로 해결한 뒤 꼭 필요한 내용만 추가합니다.
3. 이전 버전과 비교해 개선 효과와 기존 품질 유지를 확인합니다.

개선이 확인되면 반영합니다. 효과가 미확인인 후보는 따로 남기고 필요한 검증을 안내합니다. 유효한 개선안이 없으면 그대로 둡니다.

evolve는 스킬 하나에서 관찰된 문제를 다룹니다. 스킬 전체 재정비와 여러 스킬의 통합은 별도 작업입니다.
