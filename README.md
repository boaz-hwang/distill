# Skilloom

Create good skills. Make them better.

[한국어](README.ko.md) · [MIT](LICENSE)

| Skill | Use it to |
| --- | --- |
| [distill](skills/distill/README.md) | Create a skill from completed work. |
| [refine](skills/refine/README.md) | Restructure and clarify one existing skill. |
| [evolve](skills/evolve/README.md) | Improve observed behavior through localized changes. |
| [consolidate](skills/consolidate/README.md) | Review overlapping skills and merge suitable candidates. |

## Background

Skilloom grew out of a problem: skills get longer as unnecessary instructions accumulate. It trusts capable models to exercise judgment and preserves only what the intended result needs. Completed work, existing guidance, and execution feedback become evidence for creating and improving skills. Review deletion first, keep essential quality requirements, and distinguish what code can verify from what people must judge.

## Install

Paste this into your coding agent:

```text
Clone https://github.com/boaz-hwang/skilloom and install each of the four folders under skills/ as a separate skill in your skills directory.
```

If you installed distill from the old repository root, reinstall it from skills/distill.

## Use

Invoke the skill matching your task; each link above includes a copyable request. The four skills work independently.

Recommended models:

- Fable 5.1 high
- Astra 6 high
