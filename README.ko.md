# distill

방금 수행한 업무를 skill 로 남기세요.

호출하면 업무를 대신 수행해줄 skill 을 남깁니다.

[English](README.md) · [스킬 본문](SKILL.md) · [MIT](LICENSE)

| 스킬 | 역할 |
| --- | --- |
| [distill](SKILL.md) | 완료한 업무에서 스킬 생성 |
| [evolve](skills/evolve/README.ko.md) | 실제 실행 기록으로 스킬 하나 개선 |

## 배경

distill은 스킬에 불필요한 지침이 쌓여 길어지는 문제에서 출발했습니다. 최신 모델의 판단력을 믿고, 사용자가 만족한 결과를 다시 만드는 데 필요한 최소 조건만 남깁니다. 이미 끝낸 업무에서 성공한 과정과 품질 기준을 추출해 사용자 확인을 거치는 것이 핵심입니다. 구현은 모델에 맡기고, 검증 가능한 부분은 코드로, 나머지는 사람의 판단으로 평가해 스킬을 개선합니다.

## 설치

코딩 에이전트에 아래 한 줄을 붙여넣으세요.

```text
https://github.com/boaz-hwang/distill 을 git clone해서 네 스킬 폴더에 설치해줘.
```

## 사용

업무 결과에 만족하면, 작업한 세션에서 요청하세요.

```text
distill로 이 업무를 재사용 가능한 스킬로 만들어줘.
```

추천 모델:

- Fable 5.1 high
- Astra 6 high

## 동작

1. 이름 후보 3개 중 하나를 추천하고, 결과물 한 줄 설명을 확인받습니다.
2. 품질에 꼭 필요한 과정만 한 줄씩 제안하고, 수정한 과정은 다시 확인받습니다.
3. 확인한 과정으로 간결한 스킬과 필요한 템플릿·검증 코드를 만듭니다.

구현 방법은 에이전트에 맡깁니다. 객관적인 기준은 코드로 검사하고, 사람이 판단할 부분은 짧은 평가 질문으로 남깁니다.
